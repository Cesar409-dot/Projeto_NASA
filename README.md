## 🌌 Beyond Earth. Beyond Imagination.

> **What would it take to survive on Mars?**
>
> Como podemos explorar, compreender e enfrentar os desafios de viver em um planeta com condições tão diferentes das encontradas na Terra?

O **Mars Survival Guide** é uma plataforma web interativa que conecta ciência, tecnologia e exploração espacial para apresentar alguns dos principais desafios associados à presença humana em Marte.

O projeto reúne recursos de visualização geográfica, exploração científica, agricultura espacial e aspectos psicológicos de missões de longa duração.

Mais do que apresentar informações sobre Marte, a proposta é criar uma experiência na qual o usuário possa **explorar cenários, interagir com ferramentas e compreender os fundamentos científicos envolvidos na sobrevivência extraterrestre**.

### 🎯 Nossa missão

**Transformar conhecimento científico em experiências digitais acessíveis, interativas e envolventes.**

A plataforma busca aproximar o público das pesquisas relacionadas à exploração espacial, utilizando ferramentas computacionais modernas e referências científicas para incentivar a curiosidade, a aprendizagem e o pensamento crítico.

# 🪐 Explore the Mission

O Mars Survival Guide está organizado em diferentes experiências, cada uma dedicada a um aspecto importante da exploração e da sobrevivência em Marte.

## 🗺️ 01 — Mars Maps

### Explore the Red Planet

**Navegue pelo terreno marciano e descubra sua geografia.**

O módulo **Mars Maps** reúne recursos de exploração cartográfica e visualização científica de Marte.

Entre os recursos desenvolvidos e documentados estão:

- 🛰️ Visualização de dados e camadas cartográficas.
- 🌋 Exploração de regiões e características da superfície marciana.
- 📍 Pontos de interesse científico.
- 🗺️ Mapas interativos com Leaflet e React Leaflet.
- 🧭 Recursos relacionados à análise do terreno e navegação.
- 📚 Biblioteca de mapas e materiais cartográficos.
- 🔬 Integração de informações científicas e referências geoespaciais.

### Jezero Crater

Uma das regiões utilizadas pelo projeto é a **Cratera Jezero**, local de exploração do rover Perseverance, da NASA.

O projeto inclui recursos de terreno associados à região, além de documentação sobre modelos digitais de elevação, dados cartográficos e suas limitações.

**Tecnologias e conceitos:**

`Leaflet` · `React Leaflet` · `GeoTIFF` · `WMTS` · `Digital Elevation Models`

## 🌱 02 — Mars Greenhouse

### Growing Life Beyond Earth

**Como produzir alimentos em um ambiente extraterrestre?**

A agricultura espacial representa um dos desafios fundamentais para a permanência humana em missões de longa duração.

O módulo **Mars Greenhouse** explora esse problema por meio de uma experiência digital dedicada ao cultivo de plantas e ao planejamento de recursos agrícolas.

### Funcionalidades e recursos

- 🌿 Catálogo de culturas agrícolas.
- 📊 Informações para comparação entre diferentes cultivos.
- 🧪 Dados e parâmetros relacionados ao desenvolvimento vegetal.
- 🏡 Interface interativa dedicada ao ambiente de estufa.
- 📦 Recursos de organização e inventário.
- 📚 Referências sobre agricultura em ambientes espaciais.

O módulo procura conectar conceitos de biologia vegetal, produção de alimentos e sustentabilidade com os desafios encontrados em sistemas de suporte à vida.

### Contexto científico

A produção de alimentos em missões espaciais envolve fatores como:

- Disponibilidade de água.
- Iluminação e fotoperíodo.
- Nutrientes e substratos.
- Temperatura e condições ambientais.
- Consumo de recursos.
- Segurança e continuidade da produção.

Esses fatores são relevantes para o estudo de sistemas agrícolas controlados e para o desenvolvimento de estratégias de exploração espacial.

**Documentação científica:**

[GREENHOUSE_SCIENCE.md](docs/GREENHOUSE_SCIENCE.md)

## 🧠 03 — Mind Space

### The Human Side of Space Exploration

**Sobreviver em Marte não depende apenas de tecnologia. Depende também das pessoas.**

Missões espaciais de longa duração apresentam desafios psicológicos e comportamentais importantes.

Isolamento, confinamento, distância da Terra e limitações na comunicação são fatores que precisam ser considerados no planejamento de uma missão tripulada.

O **Mind Space** é o módulo dedicado à dimensão humana da exploração espacial.

### Recursos do módulo

- 👨‍🚀 Experiência interativa voltada ao contexto de missões espaciais.
- 📓 Recursos de diário do astronauta.
- 🧩 Cenários relacionados à experiência humana no espaço.
- 🧠 Conteúdo sobre fatores psicológicos e comportamentais.
- 📚 Referências científicas relacionadas à saúde e ao comportamento em missões espaciais.

### Por que isso importa?

A exploração espacial exige o desenvolvimento de soluções que considerem não apenas a integridade dos equipamentos, mas também as necessidades humanas.

O planejamento de missões prolongadas precisa considerar fatores individuais, coletivos e ambientais que podem influenciar o desempenho e o bem-estar das tripulações.

O módulo possui referências relacionadas a estudos da NASA sobre isolamento, comportamento humano e condições de vida no espaço.

**Documentação relacionada:**

[SCIENCE.md](docs/SCIENCE.md)

# 🚀 Getting Started

## Run the Mission Locally

Quer executar o Mars Survival Guide no seu computador?

Siga as instruções abaixo.

### 1. Pré-requisitos

Tenha instalados:

- Node.js compatível com Next.js 16 (versão 20.9 ou superior).
- npm.
- Git.

### 2. Clone o repositório

```bash
git clone https://github.com/Cesar409-dot/Projeto_NASA.git
```

### 3. Acesse o diretório

```bash
cd Projeto_NASA
```

### 4. Instale as dependências

```bash
npm install
```

### 5. Inicie o ambiente de desenvolvimento

```bash
npm run dev
```

### 6. Abra a aplicação

Acesse:

**http://localhost:3000**

Pronto! Sua missão pode começar. 🚀

## Help Us Explore Further

Contribuições são bem-vindas!

O Mars Survival Guide combina conhecimentos de diferentes áreas, incluindo:

- Desenvolvimento web.

### Como contribuir

**1. Faça um fork do repositório.**

**2. Crie uma branch:**

```bash
git checkout -b feat/minha-contribuicao
```

**3. Desenvolva sua contribuição.**

**4. Registre suas alterações:**

```bash
git add .
git commit -m "feat: adicionar nova funcionalidade"
```

**5. Envie sua branch:**

```bash
git push origin feat/minha-contribuicao
```

**6. Abra um Pull Request.**

Descreva o que foi alterado, por que a mudança é relevante e como ela pode ser verificada.
